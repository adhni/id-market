Build on this small market playground. Keep the focus on easy exploration.

Ground rules:
- Keep the static frontend and GitHub Pages compatibility.
- Use bundled data/series.csv and data/metadata.csv in the browser; no live API calls at runtime.
- Refresh public source data with scripts/refresh_data.py and extend the stock/index/currency list in data/catalog.json.
- Never invent observations. Keep source, units, and coverage in metadata.
- Regenerate embedded HTML data whenever the CSV files change so opening index.html directly still works.
- Keep Growth, Price, and Vs benchmark. Mixed assets compare on a common IDR basis before changing the measuring reference.
- Keep the default experience simple: ready-made comparisons, one searchable selector, and a readable chart.
- Show the actual shared comparison window when histories differ.
